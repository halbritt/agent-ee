# Logic controlled load switch

Build a compact low-side N-channel MOSFET switch for a 12 V resistive load drawing
up to 500 mA. Accept a 3.3 V logic control input, with a gate pull-down so it stays
off while disconnected. Provide labelled supply, load and logic connections,
a gate series resistor and a visible LED indicating the asserted control state.
Logic and load grounds are common. Choose stocked parts, a practical gate rating
and current margins. This version is for resistive loads; switching loss,
temperature rise and default-off behavior must be checked on hardware.
