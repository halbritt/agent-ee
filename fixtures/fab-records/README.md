# Retained fab record identity

AGENTEE-556 makes the AGENTEE-544 preservation requirement executable in
`tests/test_fab_record_identity.py`. The archive retains one owned two-layer
`fixtures/fab-export` control, its captured inputs and prerequisite records,
native process outputs, and three independently recorded expected results:
passing fab-package, passing standalone fab-consistency, and consistency with a
missing netlist prerequisite. No expected record is regenerated by the test.

Source: `campaign-2026-10-26/587-evidence/544-parity-native` under the owner's
local agent-ee evidence directory. Expected files are the `*-before.json`
records evaluated using pre-544 functions from
`24c334eebfd59558a66b17c636221b9a9ec52cc6`; their paired after records were
byte-identical. The wider retained comparison covered 57 records across the
two-layer, four-layer and corrected-CPL controls. This small regression does not
claim to rerun all 57 cases or qualify current native tools or manufacturing.

Only the native process boundary uses the existing `native_run.Recorded`
adapter. It supplies retained output files, stdout/stderr and measured durations;
the wall clock is fixed to the retained manifest time. Current export parsing,
manifest generation, composition, consistency checks, artifact sealing and
serialization run normally. The test checks exact bytes, including hashes and
limitations, without deleting fields or normalizing expected results.

The fixture excludes home/font caches and tool configuration. The synthetic
board and symbols originate in `fixtures/fab-export/generate.py`; KiCad-generated
netlist, geometry, Gerber/drill and DRC records are retained tool outputs.
