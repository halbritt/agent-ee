# Retired process documents

These files record how earlier multi-agent campaigns on agent-ee were run.
**They are not instructions.** Do not follow their dispatch, review-seat,
custody, grant, hold or reporting rules, and do not copy their structure into
new work. Current guidance is in [AGENTS.md](../../AGENTS.md).

They were moved here on 2026-11-09 under AGENTEE-634, after the owner directed
that guidance steering agents toward process machinery be removed
([decision](../decisions.md#direction-2026-11-09-capability-over-machinery)).

| [telemetry-pod-delivery-plan.md](telemetry-pod-delivery-plan.md) | Delivery plan for the telemetry pod, on hold since AGENTEE-518 |

| [contracts-argon.md](contracts-argon.md) | Adjudication contract of the first review workflow |

| [AGENTEE-526-historical-integrity.md](AGENTEE-526-historical-integrity.md) | Integrity record for historical evidence |
| [agentee-479-progress.md](agentee-479-progress.md) | Progress file of one work item |

implementer") was written by an agent and labelled as an owner rule; the
[2026-10-25 process audit](../audit/2026-10-25-process-convergence.md) records
that. It is not an owner rule.

`docs/planning/`, `docs/evaluation-plan.md`, `docs/qualification/` and
