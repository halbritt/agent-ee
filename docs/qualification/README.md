# Qualification records (frozen)

The files in this directory are per-ticket records of how one bounded
capability was checked in October and early November 2026: what was run, on
which inputs, and what remained open. They are kept because the manual and
other documents link to them.

They are records, not templates. Do not add files here, and do not copy their
form (byte offsets, digests of the tool's own files, per-ticket evidence
lists) into new work. Current guidance is in [AGENTS.md](../../AGENTS.md): a
software change is reported with the tests that cover it, and a board result
with its measured outcome in [docs/benchmarks/](../benchmarks/krt-matched-2026-11-09.md).

A record here says what was true of the code and inputs it names on its date.
It does not show that a later version of the tool behaves the same, and it is
not a claim about any board other than the one it names.
