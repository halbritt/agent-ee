# Task 3: DIFF2SE_VREF (pcbbench)

- **Dataset**: pcbbench
- **Level**: Easy
- **Domain**: Sensing
- **Primary IC**: OPA328 (SOT-23-5)
- **Input Nodes**: VINP, VINN, VREF
- **Output Nodes**: VOUT
- **Input Voltage**: 2
- **Output Voltage**: 3

## Engineering Specification

Design a differential-to-single-ended amplifier using one op-amp with a VREF offset. Assume VREF=1.65 V and differential input VINP-VINN = +/-2.0 V. Use a standard differential amplifier with matched pairs R1=R3 and R2=R4, and choose the gain so that VOUT stays within 0 to 3.0 V.
