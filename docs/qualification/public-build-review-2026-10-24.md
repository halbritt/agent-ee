# Public verification of retained builds

`agent-ee build review RUN --out DIAGNOSTIC` now uses the last completed native
candidate and the scope generated by that build. It replaces the private
input-selection helper used in the earlier acquisition qualification. It shares
the existing native review and evidence verifier with the package stage.
The command validates captured source and every completed stage, refuses an
active build writer, retains original and current tool identities, and captures
the source selection in the ordinary review. It never accepts a manufacturing
package or changes the authored checks, baseline or limitations.

The implementation was restored byte-for-byte from the owner-paused checkpoint.
The existing 52 native regression results remain applicable: no implementation
change followed that run. It passed in 78.542 seconds, with no skips, covering
`test_build_review`, `test_parts_stage`, `test_build_artwork` and
`test_requirement_map`. The real interrupted/resumed build regression now uses
the public command. Custody negatives cover stale source/stages, wrong or
unfinished candidates, escaping paths, lock ownership, output overwrite and
provenance collision. The retained red native test rejected the missing command.
